Oto Help

This page is a skeleton. The full help is written by the documentation team.

Getting started

  1. On the Home page, pick a template under Start a Beat.
  2. Click steps on a channel to place hits.
  3. Press Space to play and stop.
  4. Use Export to save your beat as audio.

Agents

Run flatpak run --command=oto-mcp io.github.luohoa97.Oto setup to connect an AI agent.

Plugins

CLAP plugins are found in ~/.clap and in installed Flatpak plugin extensions. Plugins in /usr/lib/clap on the host are not visible from the Flatpak.
